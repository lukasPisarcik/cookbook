feat: Mňamka — per-profile personal state, full-bleed recipe hero, tile-grid Špajza

- **Personal state is now scoped to a named profile**, so the app can be shared with a second person on a public URL without two kitchens overwriting each other. A first-run „Kto si?" prompt stores `{ userId: slugify(name), name }` in `localStorage` and gates the tabs until a name is chosen; the top-bar avatar switches between profiles, and typing the same name on another device resolves to the same data. The recipe corpus itself stays shared and read-only.
- **Data model:** favourites and „Dnes varím" moved off the shared recipe document into a new per-user `recipeState` table (keyed by `slug`, so re-importing the corpus never touches anyone's state), and `userId` became a required column on `pantryItems` and `shoppingItems` with user-scoped indexes. Every Convex function touching personal state now takes `userId` and scopes every read, write **and delete sweep** by it — `shopping.regenerate` deletes rows it no longer needs, so an unscoped sweep would silently have erased the other profile's whole list.
- **Migration (run it once per existing deployment):** `bunx convex run migrations:adoptLegacyState '{"userId":"lukas"}'` copies the legacy flags into `recipeState`, stamps `userId` on every owner-less pantry and shopping row, and strips the legacy fields. It is idempotent and deliberately not wired into a build step. A fresh deployment needs nothing. Also fixes a latent bug: pantry dedup was globally unique on `nameNorm`, so two people could not both own „cibuľa".
- **Recipe detail rebuilt** around a full-bleed photo that runs edge-to-edge behind the status bar with floating back and favourite buttons over it (the root layout drops its chrome on `/recepty/*`), followed by kcal-variant pills, a Čas / Kcal / Porcie stat row, macro pills and icon ingredient rows.
- **New ingredient identity system** (`ingredientIcon`): a pure two-layer function — ~150 curated diacritic-free Slovak keyword stems matched longest-first, falling back to the 22-value workbook product-type taxonomy — gives every one of the corpus's ingredient names an emoji and a tinted tile with no assets to ship. The tint always comes from the product type, so a section of rows reads as one colour family even where the emoji is generic. Reused by the detail rows, Špajza and Nákup.
- **Špajza rebuilt as a tile grid**: tap a tile to remove it (with an „Vrátiť" undo toast, since tap-to-remove is destructive-by-accident on a phone), search as tiles, and a „Časté" section of the 40 most-used ingredients where tapping adds and already-owned tiles are dimmed and non-interactive.
- **Renamed to Mňamka** — a fixed navbar wordmark replacing the active tab's name (the bottom tab bar already says which tab you are on), plus the PWA name and page-title suffix. The package, repo and Convex project keep `kucharka`.
- **Vercel-ready:** `svelte.config.js` selects `@sveltejs/adapter-vercel` on Vercel and `@sveltejs/adapter-node` locally, so `bun run e2e` keeps exercising the Node build. See the deploy runbook and the documented trust boundary (`userId` is trusted, not verified) in `README.md`.
